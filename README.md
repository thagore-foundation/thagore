# Thagore Rewrite

This branch is the clean-slate rewrite line for Thagore.

The legacy codebase has been preserved on `codex/legacy-codebase`.

What remains here on purpose:

- `.github/` for repository metadata and the `Docs Deploy` workflow
- `docs/` for architecture notes, contributor docs, and product documentation
- minimal repo meta such as `.gitignore`, `LICENSE`, and `AGENTS.md`

Everything else from the previous implementation has been stripped from this branch so the rewrite can start cleanly.
