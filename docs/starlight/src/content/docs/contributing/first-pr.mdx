# First PR Guide

<Steps>
1. Sync branch moi tu `main`.
2. Chon mot thay doi nho, co lap.
3. Them example hoac test lien quan.
4. Build va chay test trong tam.
5. Ghi ro verification commands trong PR description.
</Steps>

2. Khong tron refactor unrelated.
3. Co risk notes neu dung workflows bootstrap/runtime.
