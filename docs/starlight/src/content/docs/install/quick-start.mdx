# Quick Start: Install Thagore

Use the official release installer. It installs `thagc` from the current GitHub release and can optionally bootstrap `drago`.

## Step 1: Install

<Tabs>
  <TabItem label="Linux (Ubuntu/Debian)">

```bash
curl -fsSL https://github.com/thagore-foundation/thagore/releases/download/v0.9.6/thagup-v0.9.6.sh | sh
```

  </TabItem>
  <TabItem label="Linux (generic)">

```bash
curl -fsSL https://github.com/thagore-foundation/thagore/releases/download/v0.9.6/thagup-v0.9.6.sh | sh
```

  </TabItem>
  <TabItem label="macOS">

```bash
curl -fsSL https://github.com/thagore-foundation/thagore/releases/download/v0.9.6/thagup-v0.9.6.sh | sh
```

  </TabItem>
  <TabItem label="Windows">

```powershell
irm https://github.com/thagore-foundation/thagore/releases/download/v0.9.6/thagup-v0.9.6.ps1 | iex
```

  </TabItem>
</Tabs>

Or install a specific version explicitly:

```bash
curl -fsSL https://github.com/thagore-foundation/thagore/releases/download/v0.9.6/thagup-v0.9.6.sh | sh -s -- --tag v0.9.6
```

**Verify:**

```bash
thagc --version
drago --version
```

<Aside type="tip" title="PATH">
`thagup` adds `~/.thagore/bin` (or `%USERPROFILE%\.thagore\bin` on Windows) to user PATH. Open a new terminal if `thagc` is not found in the current shell.
</Aside>

## Step 2: First Program

Create `hello.tg`:

```tg
func main() -> i32:
  print("hello")
```

Run it:

<Tabs>
  <TabItem label="Linux/macOS">

```bash
thagc run hello.tg
```

  </TabItem>
  <TabItem label="Windows">

```powershell
thagc run hello.tg
```

  </TabItem>
</Tabs>
