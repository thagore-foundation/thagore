# Quick Start: Install Thagore

Use the official `thagup` installer — one command installs `thagc` with embedded LLVM. No separate LLVM installation required.

## Step 1: Install

<Tabs>
  <TabItem label="Linux (Ubuntu/Debian)">

```bash
curl -fsSL https://thagore.org/thagup.sh | bash
```

Installs `thagc` to `~/.thagore/bin` (embedded runtime, no system LLVM needed).

  </TabItem>
  <TabItem label="Linux (generic)">

```bash
curl -fsSL https://thagore.org/thagup.sh | bash -s -- --mode linux
```

  </TabItem>
  <TabItem label="macOS">

```bash
curl -fsSL https://thagore.org/thagup.sh | bash -s -- --mode macos
```

  </TabItem>
  <TabItem label="Windows">

```powershell
Invoke-WebRequest -Uri "https://thagore.org/thagup.ps1" -OutFile thagup.ps1
powershell -ExecutionPolicy Bypass -File .\thagup.ps1
```

  </TabItem>
</Tabs>

Or install a specific version:

```bash
curl -fsSL https://thagore.org/thagup.sh | bash -s -- --tag v0.8.2
```

`thagup` auto-detects OS + CPU architecture by default. Use `--mode` / `--arch` only when you need to override detection.

**Verify:**

```bash
thagc --version
```

<Aside type="tip" title="PATH">
Add `~/.thagore/bin` to PATH if `thagc` is not found:
`export PATH="$HOME/.thagore/bin:$PATH"`.
</Aside>

## Step 2: Write Your First Program

Create `hello.tg`:

```python title="hello.tg"
func main() -> i32:
  print("Hello, Thagore!")
  return 0
```

Compile and run:

<Tabs>
  <TabItem label="Linux/macOS">

```bash
thagc build hello.tg -o hello
./hello
```

  </TabItem>
  <TabItem label="Windows">

```powershell
thagc build hello.tg -o hello.exe
.\hello.exe
```

  </TabItem>
</Tabs>

<Aside type="note" title="No system LLVM required">
`thagc` release artifacts are self-contained for end users — no separate LLVM installation needed.
</Aside>
