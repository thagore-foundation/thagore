# Quick Start: Install Thagore

Use the official `thagup-init` installer — one command installs `thagc` + `drago`. No separate LLVM installation required.

## Step 1: Install

<Tabs>
  <TabItem label="Linux (Ubuntu/Debian)">

```bash
curl -fsSL https://thagore.org/thagup-init.sh | bash
```

Installs `thagc` and `drago` to `~/.thagore/bin` (embedded runtime, no system LLVM needed).

  </TabItem>
  <TabItem label="Linux (generic)">

```bash
curl -fsSL https://thagore.org/thagup.sh | bash -s -- --mode linux
```

  </TabItem>
  <TabItem label="macOS">

```bash
curl -fsSL https://thagore.org/thagup.sh | bash -s -- --mode macos
```

  </TabItem>
  <TabItem label="Windows">

```powershell
Invoke-WebRequest -Uri "https://thagore.org/thagup.ps1" -OutFile thagup.ps1
powershell -ExecutionPolicy Bypass -File .\thagup.ps1
```

  </TabItem>
</Tabs>

Or install a specific version:

```bash
curl -fsSL https://thagore.org/thagup.sh | bash -s -- --tag v1.0.0
```

`thagup` auto-detects OS + CPU architecture by default. Use `--mode` / `--arch` only when you need to override detection.

**Verify:**

```bash
thagc --version
drago --version
```

<Aside type="tip" title="PATH">
`thagup` auto-adds `~/.thagore/bin` (or `%USERPROFILE%\.thagore\bin` on Windows) to user PATH.
Open a new terminal if `thagc` is not found in the current shell.
</Aside>

## Step 2: First Drago Project

Create and run:

<Tabs>
  <TabItem label="Linux/macOS">

```bash
drago new hello
cd hello
drago run
```

  </TabItem>
  <TabItem label="Windows">

```powershell
drago new hello
cd hello
drago run
```

  </TabItem>
</Tabs>

<Aside type="note" title="No system LLVM required">
`thagc` release artifacts are self-contained for end users — no separate LLVM installation needed.
</Aside>
