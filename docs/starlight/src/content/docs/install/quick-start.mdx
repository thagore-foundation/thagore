# Quick Start: Install Thagore

Use the official `thagup` installer flow by platform.

## Step 1: Install

<Tabs>
  <TabItem label="Windows (UI Installer)">

```powershell
Invoke-WebRequest -Uri "https://thagore.org/thagup.exe" -OutFile thagup.exe
Start-Process -FilePath .\thagup.exe -Wait
```

`thagup.exe` maps to the latest stable Windows x86_64 installer.
For ARM64 Windows, use the direct release asset:
`https://github.com/thagore-foundation/thagore/releases/latest/download/thagore-setup-windows-arm64.exe`

  </TabItem>
  <TabItem label="Linux (Ubuntu/Debian)">

```bash
curl -fsSL https://thagore.org/thagup.sh | bash -s -- --mode ubuntu --yes
```

Installs Thagore to a safe prefix, adds PATH, and installs LLVM 21.1.8 when needed.

  </TabItem>
  <TabItem label="Linux (generic)">

```bash
curl -fsSL https://thagore.org/thagup.sh | bash -s -- --mode linux --yes
```

Installs Thagore to a safe prefix, adds PATH, and installs LLVM 21.1.8 when needed.

  </TabItem>
  <TabItem label="macOS">

```bash
curl -fsSL https://thagore.org/thagup.sh | bash -s -- --mode macos --yes
```

Installs Thagore to a safe prefix, adds PATH, and installs LLVM 21.1.8 when needed.

  </TabItem>
  <TabItem label="Portable (Android/BSD)">

```bash
curl -fsSL https://thagore.org/thagup.sh | bash -s -- --mode portable --yes
```

Installs Thagore to a safe prefix, adds PATH, and builds LLVM when needed.

  </TabItem>
</Tabs>

**Verify:**

```bash
thagore --version
```

<Aside type="tip" title="PATH">
Windows UI installer enables "Add to PATH" by default. Linux/macOS installer script updates PATH automatically.
</Aside>

## Step 2: Write Your First Program

Create `hello.tg`:

```python title="hello.tg"
func main() -> i32:
    print("Hello, Thagore!")
    return 0
```

Compile and run:

<Tabs>
  <TabItem label="Linux/macOS">

```bash
thagore build hello.tg -o hello
./hello
```

  </TabItem>
  <TabItem label="Windows">

```powershell
thagore build hello.tg -o hello.exe
.\hello.exe
```

  </TabItem>
</Tabs>
