# Quick Start: Install Thagore

Use the official `thagup` installer — one command installs `thagc` with embedded LLVM. No separate LLVM installation required.

## Step 1: Install

<Tabs>
  <TabItem label="Linux (Ubuntu/Debian)">

```bash
curl -fsSL https://thagore.org/thagup.sh | bash
```

Installs `thagc` to `~/.thagore/bin`, downloads LLVM 21 per target pack (embedded — no system LLVM needed), and adds PATH automatically.

  </TabItem>
  <TabItem label="Linux (generic)">

```bash
curl -fsSL https://thagore.org/thagup.sh | bash -s -- --mode linux
```

  </TabItem>
  <TabItem label="macOS">

```bash
curl -fsSL https://thagore.org/thagup.sh | bash -s -- --mode macos
```

  </TabItem>
  <TabItem label="Portable (Android/BSD/other)">

```bash
curl -fsSL https://thagore.org/thagup.sh | bash -s -- --mode portable
```

  </TabItem>
  <TabItem label="Windows">

```powershell
Invoke-WebRequest -Uri "https://thagore.org/thagup.exe" -OutFile thagup.exe
Start-Process -FilePath .\thagup.exe -Wait
```

  </TabItem>
</Tabs>

Or install a specific version:

```bash
curl -fsSL https://thagore.org/thagup.sh | bash -s -- --tag v0.8.1
```

Install with custom target selection:

```bash
curl -fsSL https://thagore.org/thagup.sh | bash -s -- --profile custom --targets x86_64-unknown-linux-gnu,aarch64-apple-darwin
```

**Verify:**

```bash
thagc --version
```

<Aside type="tip" title="PATH">
The installer adds `~/.thagore/bin` to PATH automatically via `.bashrc`/`.zshrc`. Restart your shell or run `source ~/.thagore/env` to activate immediately.
</Aside>

## Step 2: Write Your First Program

Create `hello.tg`:

```python title="hello.tg"
func main() -> i32:
    print("Hello, Thagore!")
    return 0
```

Compile and run:

<Tabs>
  <TabItem label="Linux/macOS">

```bash
thagc build hello.tg -o hello
./hello
```

  </TabItem>
  <TabItem label="Windows">

```powershell
thagc build hello.tg -o hello.exe
.\hello.exe
```

  </TabItem>
</Tabs>

<Aside type="note" title="No system LLVM required">
`thagc` ships with embedded LLVM 21 in each target pack — no separate LLVM installation needed.
</Aside>
