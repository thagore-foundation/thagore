# Quick Start: Install Thagore

Download a pre-built release from GitHub and write your first program in under 5 minutes. No build step, no bootstrap — CI/CD already did that for you.

---

## Step 1: Install LLVM 21

Thagore needs **LLVM 21.1.8** on your PATH. Run the official install script for your platform:

<Tabs>
  <TabItem label="🐧 Linux (Ubuntu/Debian)">

```bash
curl -fsSL https://raw.githubusercontent.com/thagore-foundation/thagore/refs/heads/main/scripts/install/ubuntu.sh | bash -s -- --yes
```

Installs LLVM 21 via the official `apt.llvm.org` repository.

  </TabItem>
  <TabItem label="🐧 Linux (generic)">

```bash
curl -fsSL https://raw.githubusercontent.com/thagore-foundation/thagore/refs/heads/main/scripts/install/linux.sh | bash -s -- --yes
```

  </TabItem>
  <TabItem label="🍎 macOS">

```bash
curl -fsSL https://raw.githubusercontent.com/thagore-foundation/thagore/refs/heads/main/scripts/install/macos.sh | bash -s -- --yes
```

Installs `llvm@21` via Homebrew. Requires [Homebrew](https://brew.sh/).

  </TabItem>
  <TabItem label="🪟 Windows (PowerShell Admin)">

```powershell
irm https://raw.githubusercontent.com/thagore-foundation/thagore/refs/heads/main/scripts/install/windows.ps1 | iex
```

Installs LLVM 21.1.8 via `winget` or `choco`.

  </TabItem>
  <TabItem label="🔧 Portable (Android/BSD/…)">

```bash
curl -fsSL https://raw.githubusercontent.com/thagore-foundation/thagore/refs/heads/main/scripts/install/portable.sh | bash -s -- --yes
```

Builds LLVM from source using `cmake` + `ninja`. Takes 30–60 min. Useful for Termux, FreeBSD, or any non-standard environment.

  </TabItem>
</Tabs>

**Verify:**

```bash
clang --version
# clang version 21.1.8 ...
```

---

## Step 2: Download the Compiler

Download the latest pre-built release (`v0.3.33-foundation`) for your platform:

<Tabs>
  <TabItem label="🐧 Linux x86-64">

```bash
curl -fsSL https://github.com/thagore-foundation/thagore/releases/download/v0.3.33-foundation/thagore-linux-x86_64.tar.gz | tar xz
chmod +x thagore
```

  </TabItem>
  <TabItem label="🐧 Linux ARM64">

```bash
curl -fsSL https://github.com/thagore-foundation/thagore/releases/download/v0.3.33-foundation/thagore-linux-arm64.tar.gz | tar xz
chmod +x thagore
```

  </TabItem>
  <TabItem label="🍎 macOS ARM64">

```bash
curl -fsSL https://github.com/thagore-foundation/thagore/releases/download/v0.3.33-foundation/thagore-macos-arm64.tar.gz | tar xz
chmod +x thagore
```

  </TabItem>
  <TabItem label="🪟 Windows">

```powershell
Invoke-WebRequest -Uri "https://github.com/thagore-foundation/thagore/releases/download/v0.3.33-foundation/thagore-windows-x86_64.zip" -OutFile thagore.zip
Expand-Archive thagore.zip -DestinationPath .
```

  </TabItem>
</Tabs>

**Verify:**

```bash
./thagore --version
```

<Aside type="tip" title="Add to PATH (optional)">
To use `thagore` from anywhere, move it to a directory on your PATH:

```bash
# Linux / macOS
sudo mv thagore /usr/local/bin/thagore

# Windows — add the folder to your System PATH via Settings
```
</Aside>

---

## Step 3: Write Your First Program

Create a file `hello.tg`:

```python title="hello.tg"
func main() -> i32:
    print("Hello, Thagore!")
    return 0
```

Compile and run:

<Tabs>
  <TabItem label="🐧 Linux / 🍎 macOS">

```bash
./thagore build hello.tg -o hello
./hello
```

  </TabItem>
  <TabItem label="🪟 Windows">

```powershell
.\thagore.exe build hello.tg -o hello.exe
.\hello.exe
```

  </TabItem>
</Tabs>

```
Hello, Thagore!
```

🎉 That's it — you're up and running!

---

## Step 4: Try More Examples

Download and run examples directly from the repo:

```bash
# Fibonacci
curl -fsSL -o fib.tg https://raw.githubusercontent.com/thagore-foundation/thagore/refs/heads/main/examples/fib.tg
./thagore build fib.tg -o fib && ./fib
# 9227465

# Read user input
curl -fsSL -o input.tg https://raw.githubusercontent.com/thagore-foundation/thagore/refs/heads/main/examples/console_input_i32.tg
./thagore build input.tg -o input_demo && ./input_demo

# Structs
curl -fsSL -o method.tg https://raw.githubusercontent.com/thagore-foundation/thagore/refs/heads/main/examples/method.tg
./thagore build method.tg -o method && ./method
```
