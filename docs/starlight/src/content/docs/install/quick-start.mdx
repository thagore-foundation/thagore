# Quick Start: Install Thagore

Use the official release installer. It installs `thagc` from the latest GitHub release and always bootstraps `drago`.

## Step 1: Install

<Tabs>
  <TabItem label="Linux (Ubuntu/Debian)">

```bash
curl -fsSL https://github.com/thagore-foundation/thagore/releases/latest/download/thagup.sh | sh
```

  </TabItem>
  <TabItem label="Linux (generic)">

```bash
curl -fsSL https://github.com/thagore-foundation/thagore/releases/latest/download/thagup.sh | sh
```

  </TabItem>
  <TabItem label="macOS">

```bash
curl -fsSL https://github.com/thagore-foundation/thagore/releases/latest/download/thagup.sh | sh
```

  </TabItem>
  <TabItem label="Windows">

```powershell
irm https://github.com/thagore-foundation/thagore/releases/latest/download/thagup.ps1 | iex
```

  </TabItem>
</Tabs>

Or install a specific version explicitly:

```bash
curl -fsSL https://github.com/thagore-foundation/thagore/releases/latest/download/thagup.sh | sh -s -- --tag v0.9.7
```

**Verify:**

```bash
thagc --version
```

The installer now bootstraps `drago` by default. Verify it with `drago --version`.

<Aside type="tip" title="PATH">
`thagup` installs into `~/.local/share/thagore/bin` on POSIX by default and `%LOCALAPPDATA%\Programs\Thagore\bin` on Windows. The Windows installer updates user PATH automatically. Open a new terminal if `thagc` is not found in the current shell.
</Aside>

## Step 2: First Program

Create `hello.tg`:

```tg
func main() -> i32:
  print("hello")
  return 0
```

Run it:

<Tabs>
  <TabItem label="Linux/macOS">

```bash
thagc run hello.tg
```

  </TabItem>
  <TabItem label="Windows">

```powershell
thagc run hello.tg
```

  </TabItem>
</Tabs>

Build a native executable:

<Tabs>
  <TabItem label="Linux/macOS">

```bash
thagc build hello.tg
./hello
```

  </TabItem>
  <TabItem label="Windows">

```powershell
thagc build hello.tg
.\hello.exe
```

  </TabItem>
</Tabs>
