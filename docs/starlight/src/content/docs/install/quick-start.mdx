# Quick Start: Install Thagore

Follow this guide to install the Thagore compiler on your system and run your first program. The entire process takes about **10 minutes**.

<Aside type="tip" title="TL;DR — Fastest Path">
```bash
# 1. Clone the repo
git clone https://github.com/thagore-foundation/thagore.git && cd thagore

# 2. Run the platform installer (installs LLVM 21 + Thagore)
# Windows (PowerShell as Admin):
powershell -ExecutionPolicy Bypass -File scripts\install\install-windows.ps1
# Linux:
bash scripts/install/install-linux.sh
# macOS:
bash scripts/install/install-macos.sh

# 3. Bootstrap the compiler
# Windows:
cmd /c scripts\bootstrap.bat
# Linux/macOS:
bash scripts/bootstrap.sh

# 4. Write & run your first program
echo 'print("Hello Thagore!")' > hello.tg
stage2.exe build hello.tg -o hello.exe  # Windows
./stage2 build hello.tg -o hello        # Linux/macOS
```
</Aside>

---

## Step 1: System Requirements

Before installing, make sure your system meets these requirements:

| Requirement | Minimum |
|-------------|---------|
| **OS** | Windows 10+, Ubuntu 20.04+, macOS 12+ (Apple Silicon or Intel) |
| **Disk space** | ~2 GB (LLVM + compiler + runtime) |
| **RAM** | 4 GB recommended |
| **Git** | Any version (for cloning the repo) |

## Step 2: Install LLVM 21

Thagore compiles to native code via LLVM, so you need **LLVM 21.1.8** installed first.

<Tabs>
  <TabItem label="🪟 Windows">

### Option A: Automated (Recommended)

The install script handles everything via `winget` or `chocolatey`:

```powershell
# Run as Administrator
powershell -ExecutionPolicy Bypass -File scripts\install\windows.ps1 -yes
```

This will:
- Detect your architecture (x86-64 or ARM64)
- Install LLVM 21.1.8 via `winget` or `choco`
- Verify `clang.exe` is on PATH

### Option B: Manual

1. **Using winget:**
   ```powershell
   winget install --id LLVM.LLVM --version 21.1.8 --silent
   ```

2. **Using Chocolatey:**
   ```powershell
   choco install llvm --version=21.1.8 -y
   ```

3. **Manual download:**
   - Go to [LLVM Releases](https://github.com/llvm/llvm-project/releases/tag/llvmorg-21.1.8)
   - Download `LLVM-21.1.8-win64.exe` (or the `.tar.xz` archive)
   - Install or extract to `C:\Program Files\LLVM`
   - Add `C:\Program Files\LLVM\bin` to your system `PATH`

### Verify

```powershell
clang --version
# Expected output: clang version 21.1.8 ...
```

  </TabItem>
  <TabItem label="🐧 Linux (Ubuntu/Debian)">

### Option A: Automated (Recommended)

```bash
bash scripts/install/ubuntu.sh --yes
```

This will:
- Run `apt-get update`
- Download and execute the official LLVM install script
- Install LLVM 21 with all components
- Add `/usr/lib/llvm-21/bin` to PATH if needed

### Option B: Manual

```bash
# Install from LLVM's official apt repository
curl -fsSL https://apt.llvm.org/llvm.sh -o /tmp/llvm.sh
chmod +x /tmp/llvm.sh
sudo /tmp/llvm.sh 21 all

# If clang is not found, add to PATH:
export PATH="/usr/lib/llvm-21/bin:$PATH"
```

### Verify

```bash
clang --version
# Expected output: clang version 21.1.8 ...
```

  </TabItem>
  <TabItem label="🍎 macOS">

### Option A: Automated (Recommended)

Requires [Homebrew](https://brew.sh/):

```bash
bash scripts/install/macos.sh --yes
```

This will:
- Run `brew update`
- Tap `thagore-foundation/llvm`
- Install `llvm@21`
- Add the LLVM bin directory to PATH

### Option B: Manual

```bash
brew update
brew install llvm@21

# Add to PATH (Apple Silicon):
export PATH="$(brew --prefix llvm@21)/bin:$PATH"

# Add to your shell profile (~/.zshrc) for persistence:
echo 'export PATH="$(brew --prefix llvm@21)/bin:$PATH"' >> ~/.zshrc
```

### Verify

```bash
clang --version
# Expected output: clang version 21.1.8 ...
```

  </TabItem>
  <TabItem label="🔧 Portable (Build from Source)">

For environments without package managers:

```bash
bash scripts/install/portable.sh --yes
```

**Requirements:** `git`, `cmake`, `ninja`

This clones LLVM 21.1.8 from source and builds `clang` + `lld` into `~/.thagore/llvm-21.1.8/`. It takes 30–60 minutes.

```bash
# Custom prefix:
THAGORE_LLVM_PREFIX=/opt/llvm-21 bash scripts/install/portable.sh --yes

# Add to PATH:
export PATH="$HOME/.thagore/llvm-21.1.8/bin:$PATH"
```

  </TabItem>
</Tabs>

## Step 4: Get the Stage1 Seed & Runtime

The **Stage1 seed** is a pre-built Thagore compiler binary used to bootstrap the full compiler. The **runtime ABI** provides core functions that compiled programs link against.

Download both from the latest release:

```bash
# Check the latest seed tag at:
# https://github.com/thagore-foundation/thagore/releases/tag/v0.3.25-stage1-seed
```

<Tabs>
  <TabItem label="🪟 Windows">

Download and place in the project root directory:
- `stage1.exe` — the Stage1 seed compiler
- `thag_runtime.lib` (or `thagore-runtime-windows.lib`) — the runtime library

```powershell
# Verify the files are in place
dir stage1.exe
dir thag_runtime.lib
```

  </TabItem>
  <TabItem label="🐧 Linux">

Download and place in the project root directory:
- `stage1` — the Stage1 seed compiler
- `libthag_runtime.a` (or `thagore-runtime-linux.a`) — the runtime library

```bash
chmod +x stage1
ls -la stage1 libthag_runtime.a
```

  </TabItem>
  <TabItem label="🍎 macOS">

Download and place in the project root directory:
- `stage1` — the Stage1 seed compiler
- `libthag_runtime.a` (or `thagore-runtime-macos.a`) — the runtime library

```bash
chmod +x stage1
ls -la stage1 libthag_runtime.a
```

  </TabItem>
</Tabs>

<Aside type="note" title="Why do I need a seed?">
Thagore is **self-hosted** — the compiler is written in Thagore itself. To compile the compiler, you need an existing Thagore compiler. The Stage1 seed breaks this chicken-and-egg cycle. Once you bootstrap, you won't need it again (Stage2 can compile itself).
</Aside>

## Step 5: Bootstrap the Compiler

The bootstrap process uses the Stage1 seed to build the full self-hosted compiler:

<Tabs>
  <TabItem label="🪟 Windows">

```powershell
cmd /c scripts\bootstrap.bat
```

  </TabItem>
  <TabItem label="🐧 Linux / 🍎 macOS">

```bash
bash scripts/bootstrap.sh
```

  </TabItem>
</Tabs>

### What happens during bootstrap:

```
[1/4] Build stage2 from stage1...
      stage1 compiles src/thagore.tg → stage2.exe

[2/4] Rebuild stage2b from stage2...
      stage2 compiles src/thagore.tg → stage2b.exe (proves self-hosting!)

[3/4] Build hello_v2 from stage2b...
      stage2b compiles examples/hello.tg → hello_v2.exe

[4/4] Run hello_v2...
      hello_v2.exe → "Hello Self-Hosted World!"

[OK] Stage1-only bootstrap cycle completed.
```

<Aside type="caution" title="Bootstrap Failures">
If the bootstrap fails:
1. Verify LLVM/Clang is on PATH: `clang --version`
2. Verify `stage1.exe` and runtime ABI are in the project root
3. Ensure `.tg` files have Unix line endings (LF, not CRLF)
4. Check that Python 3 is available (used by `build_runtime_abi.py`)
</Aside>

After a successful bootstrap, you now have `stage2.exe` (or `./stage2`) — the fully self-hosted Thagore compiler!

## Step 6: Write Your First Program

Create a file named `hello.tg`:

```python title="hello.tg"
func main() -> i32:
    print("Hello, Thagore!")
    print("Your first compiled program 🚀")
    return 0
```

Compile and run it:

<Tabs>
  <TabItem label="🪟 Windows">

```powershell
.\stage2.exe build hello.tg -o hello.exe
.\hello.exe
```

  </TabItem>
  <TabItem label="🐧 Linux / 🍎 macOS">

```bash
./stage2 build hello.tg -o hello
./hello
```

  </TabItem>
</Tabs>

**Expected output:**
```
Hello, Thagore!
Your first compiled program 🚀
```

🎉 **Congratulations!** You just compiled and ran your first Thagore program!

## Step 7: Try More Examples

The `examples/` directory has ready-to-run programs:

```bash
# Fibonacci (recursive)
stage2 build examples/fib.tg -o fib
./fib
# Output: 9227465

# Structs and methods
stage2 build examples/method.tg -o method
./method
# Output: 200  1

# Operator overloading
stage2 build examples/ops.tg -o ops
./ops
# Output: 4  6  11

# C FFI (calling sqrtf from libc)
stage2 build examples/ffi.tg -o ffi
./ffi
# Output: 5.0

# Dynamic list
stage2 build examples/dynamic_list.tg -o dynlist
./dynlist
```

## Step 8: System-Wide Installation (Optional)

If you want `thagore` available globally as a command:

<Tabs>
  <TabItem label="🪟 Windows">

Run as Administrator:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\install\install-windows.ps1
```

This installs to `C:\Program Files\Thagore\` and adds it to `PATH`. After installation:
- **Binary:** `C:\Program Files\Thagore\bin\thagore.exe`
- **Alias:** `C:\Program Files\Thagore\bin\thag.exe`
- **Stdlib:** `C:\Program Files\Thagore\lib\std`

```powershell
# After restarting your terminal:
thagore --version
thagore build hello.tg -o hello.exe
```

  </TabItem>
  <TabItem label="🐧 Linux">

```bash
sudo bash scripts/install/install-linux.sh
```

Installs to `/opt/thagore/` and symlinks to `/usr/local/bin/`:
- **Binary:** `/usr/local/bin/thagore`
- **Alias:** `/usr/local/bin/thag`
- **Stdlib:** `/opt/thagore/lib/std`

```bash
thagore --version
thagore build hello.tg -o hello
```

  </TabItem>
  <TabItem label="🍎 macOS">

```bash
sudo bash scripts/install/install-macos.sh
```

Installs to `/usr/local/thagore/` and symlinks to `/usr/local/bin/`:
- **Binary:** `/usr/local/bin/thagore`
- **Alias:** `/usr/local/bin/thag`
- **Stdlib:** `/usr/local/thagore/lib/std`

```bash
thagore --version
thagore build hello.tg -o hello
```

## Folder Structure After Installation

```
thagore/
├── stage1.exe          # Stage1 seed (bootstrap only)
├── stage2.exe          # ✅ Your compiler — use this!
├── stage2b.exe         # Self-host verification binary
├── thag_runtime.lib    # Runtime ABI library
├── src/                # Compiler source code
├── lib/                # Standard library (fs, string, io, env, ...)
├── std/                # Core primitives (core, list, string)
├── examples/           # Example programs
├── tests/              # Test suite
├── scripts/            # Build & install scripts
└── docs/               # Documentation
```
