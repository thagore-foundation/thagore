# Windows Bootstrap

<Steps>
1. Chuan bi Stage1 seed binary (`stage1.exe`).

2. Build chain Stage1 -> Stage2 -> Stage2b:

   ```bat title="scripts/bootstrap.bat"
   stage1.exe build src/thagore.tg -o stage2.exe
   stage2.exe build src/thagore.tg -o stage2b.exe
   stage2b.exe build examples/hello.tg -o hello_v2.exe
   hello_v2.exe
   ```

3. Hoac chay script tu dong:

   ```bat
   cmd /c scripts\bootstrap.bat
   ```

4. Verify build output:

   ```bat
   stage2.exe --version
   ```
</Steps>

<Aside type="tip" title="Guard Timeout">
Ban co the dung `scripts/bootstrap_stage.bat` de chay qua `stage_guard.py`, tranh treo tien trinh khi stage build loi/hang.
</Aside>
