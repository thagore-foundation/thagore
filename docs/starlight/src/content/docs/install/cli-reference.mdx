# CLI Reference

Các command chính (runtime `__thg_cli_main_native`):

```text
thagore build <file.tg> [-o output]
             [--autofix off|safe|aggressive] [--autofix-lock <path>]
             [--autofix-lock-strict] [--autofix-locked] [--autofix-workspace]
             [--autofix-max-iterations N] [--autofix-max-files N] [--autofix-exclude a,b,c]
thagore test [filter] [--workspace] [--package <name>|a,b] [--exclude <a,b,c>]
             [--exclude-package <a,b,c>] [--no-run] [--fail-fast] [--json]
             [--message-format json|human] [--list]
thagore fix doctor <entry.tg> [--workspace] [--exclude a,b,c] [--lock <path>] [--lock-strict] [--locked]
                        [--message-format json|human]
thagore fix dry-run <entry.tg> [--workspace] [--exclude a,b,c] [--lock <path>] [--lock-strict] [--locked]
                         [--message-format json|human]
thagore fix apply <entry.tg> [--level safe|aggressive] [--workspace] [--exclude a,b,c]
                 [--max-files N] [--max-iterations N] [--lock <path>] [--lock-strict] [--locked]
                 [--message-format json|human]
thagore fix explain <entry.tg> [--json] [--workspace] [--exclude a,b,c] [--lock <path>] [--lock-strict] [--locked]
                   [--message-format json|human]
thagore fix rollback <session-id>
thagore --emit-llvm <file.tg> [-o output.ll]
thagore --emit-llvm-internal <file.tg> [-o output.ll]
thagore install toolchain [--yes] [--dry-run]
                         [--llvm-version 21.1.8]
                         [--target-os auto|windows|ubuntu|macos|linux|portable]
                         [--arch auto|amd64|x86_64|arm64|aarch64]
thagore --version
thagore --help
```

## Examples

```bash title="build-hello.sh" mark={1}
thagore build examples/hello.tg -o hello.exe
```

```bash title="emit-llvm.sh" mark={1}
thagore --emit-llvm examples/fib.tg -o fib.ll
```

```bash title="test-no-run.sh" mark={1}
thagore test autofix --no-run --fail-fast
```

```bash title="test-workspace-packages.sh" mark={1}
thagore test --workspace --package autofix --package std --exclude-package std --no-run
```

```bash title="test-json-stream.sh" mark={1}
thagore test --workspace --message-format json --fail-fast
```

```bash title="fix-workspace-locked.sh" mark={1}
thagore fix apply src/main.tg --workspace --lock thagore.fix.lock --locked
```

```bash title="fix-json-stream.sh" mark={1}
thagore fix apply src/main.tg --workspace --message-format json
```

JSON mode emits one object per line (`suite started`, per-test `build/run`, final `suite` summary).
Each event includes `schema_version=1`, `event_schema="thagore.test.v1"`, and a per-run `run_id`.
Final summary includes `duration_ms` and `report_path`.
Structured run reports are written to `.thagore/test/reports/<run_id>.json`.
When available, per-test events include `log_path` for build/run logs under `.thagore/test/log/`.

## Exit Codes

1. `0`: success.
2. `2`: invalid usage (missing file/output).
3. non-zero linker/codegen: build/link failure.
