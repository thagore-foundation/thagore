# Unix (Linux / macOS) Bootstrap

## Quick Start

```bash
bash scripts/bootstrap.sh
```

This script performs the full Stage1 → Stage2 → Stage2b bootstrap cycle and validates sample outputs.

## Manual Bootstrap

<Tabs>
  <TabItem label="Linux">

```bash
# Step 1: Use the seed to compile Stage2
./stage1 build src/thagore.tg -o stage2

# Step 2: Self-host
./stage2 build src/thagore.tg -o stage2b

# Step 3: Verify
./stage2 build examples/hello.tg -o hello
./hello
# Output: Hello Self-Hosted World!
```

  </TabItem>
  <TabItem label="macOS">

```bash
# Step 1: Compile with seed (ensure LLVM 21 is on PATH)
./stage1 build src/thagore.tg -o stage2

# Step 2: Self-host
./stage2 build src/thagore.tg -o stage2b

# Step 3: Verify
./stage2 build examples/hello.tg -o hello
./hello
```

  </TabItem>
</Tabs>

## Runtime ABI

On Unix systems, the runtime library is `libthag_runtime.a`. Ensure it is in the working directory or a standard library path when linking.

| Platform | Runtime File |
|----------|-------------|
| Linux (x86-64) | `thagore-runtime-linux.a` |
| Linux (ARM64) | `thagore-runtime-linux-arm64.a` |
| macOS (ARM64) | `thagore-runtime-macos.a` |

## Seed Rotation Policy

Seeds are promoted through the `Seed Stage1 Assets` CI workflow. After promotion, the `BOOTSTRAP_STAGE1_TAG` variable must be updated in:
- `.github/workflows/ci.yml`
- `.github/workflows/selfhost-matrix.yml`
- `.github/workflows/release.yml`
- `.github/workflows/bootstrap-seed.yml`

<Aside type="note" title="No C++ Fallback">
Thagore enforces a strict bootstrap policy: there is no Stage0 fallback, no C++ runtime build path, and no implicit fallback in any workflow.
</Aside>
