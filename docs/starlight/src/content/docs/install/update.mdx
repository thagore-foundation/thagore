# Updating Thagore

After v1.2b, update and dependency flows are owned by `drago`.

## Check versions

```bash
thagc --version
drago --version
```

## Apply updates

```bash
drago update
```

`drago update` refreshes dependencies and toolchain references used by project workflows.

## Typical workflow

```bash
drago update
drago build
drago test
```

## Command reference

| Command | Description |
|---------|-------------|
| `drago update` | Apply update flow for managed toolchain/dependencies |
| `thagc --version` | Print compiler version |
| `drago --version` | Print drago version |
