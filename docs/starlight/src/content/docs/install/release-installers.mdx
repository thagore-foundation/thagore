# Release & Installers

## Release Artifacts

Each Thagore release publishes the following artifacts on GitHub Releases:

### Installer entry points

| Artifact | Purpose |
|----------|---------|
| `thagup.sh` | Installer for Linux/macOS (auto-detect OS + CPU arch) |
| `thagup.ps1` | Installer for Windows PowerShell (auto-detect CPU arch) |

### Core bundles (compiler binary)

| Artifact | Platform/arch | Contents |
|----------|---------------|----------|
| `thagc-core-linux-x86_64.tar.gz` | Linux x86-64 | `thagc` binary |
| `thagc-core-linux-aarch64.tar.gz` | Linux ARM64 | `thagc` binary |
| `thagc-core-macos-x86_64.tar.gz` | macOS x86-64 | `thagc` binary |
| `thagc-core-macos-aarch64.tar.gz` | macOS ARM64 | `thagc` binary |
| `thagc-core-windows-x86_64.tar.gz` | Windows x86-64 | `thagc.exe` binary |
| `thagc-core-windows-aarch64.tar.gz` | Windows ARM64 | `thagc.exe` binary |

### Checksums

| File | Covers |
|------|--------|
| `SHA256SUMS-thagc.txt` | Installers + all core artifacts |

<Aside type="note" title="Embedded LLVM">
Runtime support is already embedded into the released `thagc` binary.
</Aside>

<Aside type="note" title="What thagup installs">
`thagup` installs both `thagc` and `drago` by default, then wires launchers into `~/.thagore/bin` (or `%USERPROFILE%\.thagore\bin`).
</Aside>

## Using Pre-built Releases

### Recommended: thagup installer

Linux/macOS:

```bash
curl -fsSL https://thagore.org/thagup.sh | bash
```

Windows:

```powershell
Invoke-WebRequest -Uri "https://thagore.org/thagup.ps1" -OutFile thagup.ps1
powershell -ExecutionPolicy Bypass -File .\thagup.ps1
```

Verify:

```bash
thagc --version
drago --version
```

### Manual installation (Linux x86-64 example)

```bash
# Download core bundle and verify checksum
curl -fsSL https://github.com/thagore-foundation/thagore/releases/latest/download/thagc-core-linux-x86_64.tar.gz -o thagc-core-linux-x86_64.tar.gz
curl -fsSL https://github.com/thagore-foundation/thagore/releases/latest/download/SHA256SUMS-thagc.txt -o SHA256SUMS-thagc.txt
sha256sum --check --ignore-missing SHA256SUMS-thagc.txt

# Extract
mkdir -p ~/.thagore/toolchains/stable
tar -xzf thagc-core-linux-x86_64.tar.gz -C ~/.thagore/toolchains/stable

# Add to PATH
echo 'export PATH="$HOME/.thagore/bin:$PATH"' >> ~/.bashrc
export PATH="$HOME/.thagore/bin:$PATH"
ln -sf ~/.thagore/toolchains/stable/bin/thagc ~/.thagore/bin/thagc

thagc --version
```

## thagup entry points

| Endpoint | Description |
|----------|-------------|
| `https://thagore.org/thagup.sh` | Latest stable installer script (Linux/macOS) |
| `https://thagore.org/thagup.ps1` | Latest stable installer script (Windows PowerShell) |
| `https://raw.githubusercontent.com/thagore-foundation/thagore/main/tooling/release/thagup.sh` | Raw source (always current `main`) |

## thagup installer options

Use these options when invoking `thagup.sh`:

```bash
thagup.sh --tag v1.0.0                # install specific thagc release
thagup.sh --drago-tag v1.0.0          # pin drago version
thagup.sh --without-drago             # install thagc only
thagup.sh --channel nightly           # install into custom channel directory
thagup.sh --install-root /opt/thagore # custom install root
thagup.sh --force                     # overwrite existing channel
```

## CI/CD Pipelines

Thagore uses multiple CI pipelines to ensure correctness:

| Workflow | Purpose |
|----------|---------|
| **CI** | Build + test on push/PR |
| **Selfhost Matrix** | Verify self-hosting across all target platforms |
| **Release** | Build release artifacts and publish |
| **Bootstrap Seed** | Generate and promote new Stage1 seed binaries |

## Merge Requirements

A merge to `main` requires **3 consecutive green runs**:
- ✅ CI pipeline
- ✅ Selfhost Matrix
- ✅ Release (dry-run)

<Aside type="caution" title="Strict Policy">
There is no automatic fallback. If any pipeline fails, the merge is blocked until all three pass consecutively.
</Aside>
