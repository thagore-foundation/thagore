# I/O, Env & Process

## `std.io` — Console I/O

The only I/O module in the current compiler is `std.io`. See [std.io](/stdlib/io/) for the complete reference.

```thagore
import std.io as io

func main() -> i32:
  let line = io.read_line()
  println(line)
  return 0
```

## Modules that do not exist

The following modules are **not present** in the current compiler:

| Name | Status |
|------|--------|
| `lib/io.tg` | not implemented |
| `lib/env.tg` | not implemented |
| `lib/process.tg` | not implemented |
| `lib/map.tg` | not implemented |
| `lib/string.tg` | not implemented — use `std.string` |

Environment variables, command-line arguments, shell execution, and maps are not exposed through the standard library in the current compiler.
