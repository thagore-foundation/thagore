# Path, HTTP & Time

## `std.time` — Time Utilities

The `std.time` module provides a runtime clock and a basic sleep primitive.

```thagore
import std.time as time
```

### API

| Function | Signature | Description |
|----------|-----------|-------------|
| `now_ms` | `func now_ms() -> i64` | Current time in milliseconds since epoch |
| `sleep_ms` | `func sleep_ms(ms: i64)` | Pause the current thread for at least `ms` milliseconds |

### Example

```thagore
import std.time as time

func main() -> i32:
  let start = time.now_ms()
  let i: i32 = 0
  while (i < 1000):
    i = i + 1
  let elapsed = time.now_ms() - start
  if (elapsed > 0):
    return 0
  return 1
```

`now_ms` returns `i64`. There is no `string.from_i64` in the current standard library.

```thagore
import std.time as time

func main() -> i32:
  let start = time.now_ms()
  time.sleep_ms(25)
  let elapsed = time.now_ms() - start
  if (elapsed >= 10):
    return 0
  return 1
```

## Modules that do not exist

The following modules are **not present** in the current compiler:

| Name | Status |
|------|--------|
| `lib/path.tg` | not implemented |
| `lib/http.tg` | not implemented |
| `lib/fs.tg` | not implemented |

File system access, HTTP requests, and path manipulation are not provided by the current standard library.
