# Core & std Modules

The standard library in the current compiler consists of four modules: `std.io`, `std.math`, `std.string`, and `std.time`. Each has its own reference page.

| Module | Import | Description |
|--------|--------|-------------|
| `std.io` | `import std.io as io` | stdin reading functions |
| `std.math` | `import std.math as math` | math constants and functions |
| `std.string` | `import std.string as string` | string conversion and manipulation |
| `std.time` | `import std.time as time` | current time in milliseconds |

## Modules that do not exist

The following modules are **not present** in the current compiler and should not be referenced in code:

| Name | Status |
|------|--------|
| `std/core.tg` | not implemented |
| `std/list.tg` | not implemented |
| `StringBuilder` | not implemented |
| `List` struct | not implemented |
| `malloc` / `free` / `memcpy` | not exposed as stdlib functions |

For memory-level interop, use `extern func` to declare C functions directly. See [FFI & Import](/syntax/ffi-and-import/) for details.
