# Beginner Algorithms Tutorial

This guide uses only features available in the current compiler.

## 1. Conditionals and loops

```thagore
func abs_i32(x: i32) -> i32:
  if (x < 0):
    return 0 - x
  return x

func sum_to(n: i32) -> i32:
  let i: i32 = 1
  let total: i32 = 0
  while (i <= n):
    total = total + i
    i = i + 1
  return total
```

## 2. Linear search over input array

Arrays are supplied by runtime APIs like `io.read_ints`. Use `for item in items:` to iterate.

```thagore
import std.io as io
import std.string as string

func find_first_positive(items: Array[i32]) -> i32:
  for item in items:
    if (item > 0):
      return item
  return -1

func main() -> i32:
  let n = io.read_int()
  let values = io.read_ints(n)
  let result = find_first_positive(values)
  println(string.from_int(result))
  return 0
```

## 3. Reduction over array

```thagore
import std.io as io
import std.string as string

func sum_items(items: Array[i32]) -> i32:
  let total: i32 = 0
  for item in items:
    total = total + item
  return total

func main() -> i32:
  let n = io.read_int()
  let values = io.read_ints(n)
  println(string.from_int(sum_items(values)))
  return 0
```

## 4. Recursive algorithms

```thagore
func fib(n: i32) -> i32:
  if (n <= 1):
    return n
  return fib(n - 1) + fib(n - 2)

func factorial(n: i32) -> i32:
  if (n <= 1):
    return 1
  return n * factorial(n - 1)
```

## 5. Manual counting with while

There is no numeric range syntax (`0..10`). Use `while` instead:

```thagore
import std.string as string

func count_even(limit: i32) -> i32:
  let i: i32 = 0
  let count: i32 = 0
  while (i <= limit):
    if (i % 2 == 0):
      count = count + 1
    i = i + 1
  return count

func main() -> i32:
  println(string.from_int(count_even(10)))
  return 0
```

## Compile and run

```bash
thagc build beginner.tg -o beginner
./beginner
```

## Current limitations

- No fixed-size array literals (`[1, 2, 3]` does not exist)
- No array indexing by position (`arr[i]` does not exist)
- No `len()` builtin for arrays
- No range loops (`0..10` does not exist) — use `while`
- Use `for item in items:` to iterate over `Array[T]` values from runtime APIs
