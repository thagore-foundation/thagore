# Idiomatic Patterns

## Pattern 1: Struct methods with explicit self

Methods in `impl` blocks take an explicit `self` parameter and return a value. There is no mutation in place.

```thagore
struct Counter:
  value: i32

impl Counter:
  func current(self) -> i32:
    return self.value

  func bump(self) -> i32:
    return self.value + 1
```

## Pattern 2: Error handling with return codes

Use `i32` return codes for error signaling:

```thagore
func validate(n: i32) -> i32:
  if (n < 0):
    return 1
  if (n > 1000):
    return 2
  return 0

func main() -> i32:
  let rc = validate(42)
  if (rc != 0):
    println("Validation failed")
  return rc
```

## Pattern 3: String building with concat

Use `std.string.concat` to assemble strings:

```thagore
import std.string as string

func build_label(key: str, value: i32) -> str:
  return string.concat(key, string.concat("=", string.from_int(value)))

func main() -> i32:
  println(build_label("count", 42))
  return 0
```

## Pattern 4: Reading and processing input

```thagore
import std.io as io
import std.string as string

func main() -> i32:
  let n = io.read_int()
  let values = io.read_ints(n)
  let total: i32 = 0
  for v in values:
    total = total + v
  println(string.from_int(total))
  return 0
```

## Pattern 5: Nested struct access

```thagore
struct Point:
  x: i32
  y: i32

struct Rect:
  origin: Point
  width: i32
  height: i32

func area(rect: Rect) -> i32:
  return rect.width * rect.height

func offset_x(rect: Rect) -> i32:
  return rect.origin.x
```

## Pattern 6: Using std.math helpers

```thagore
import std.math as math

func clamp_score(value: i32) -> i32:
  return math.clamp(value, 0, 100)

func hypotenuse(a: f64, b: f64) -> f64:
  return math.sqrt(math.pow(a, 2.0) + math.pow(b, 2.0))
```

## Pattern 7: extern func for C FFI

Wrap C functions with type-safe Thagore wrappers:

```thagore
extern func sqrt(x: f64) -> f64
extern func pow(base: f64, exp: f64) -> f64

func safe_sqrt(x: f64) -> f64:
  if (x < 0.0):
    return 0.0
  return sqrt(x)
```

## Pattern 8: Test with return codes

```thagore
func test_addition() -> i32:
  let result = 2 + 3
  if (result != 5):
    println("FAIL: test_addition")
    return 1
  println("PASS: test_addition")
  return 0

func main() -> i32:
  let failures: i32 = 0
  failures = failures + test_addition()
  if (failures > 0):
    println("Some tests failed!")
  else:
    println("All tests passed!")
  return failures
```

## Style summary

- **2-space indentation** — tabs are rejected
- **Conditions require parentheses** — `if (x > 0):`
- **No `++`/`--`** — use `i = i + 1`
- **No string `+`** — use `string.concat(a, b)`
- **No array literals** — arrays come from `io.read_ints`, `string.split`, etc.
- **`func main() -> i32:`** for all programs; return `0` for success
