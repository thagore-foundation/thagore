# Pitfalls & Debugging

## Common Pitfalls

### 1. Missing parentheses in `if`/`while`

❌ **Wrong:**
```thagore
if x > 0:
  println("positive")
```

✅ **Correct:**
```thagore
if (x > 0):
  println("positive")
```

Thagore requires parentheses around conditions in `if` and `while`.

### 2. No `++` or `--` operators

❌ **Wrong:**
```thagore
i++
```

✅ **Correct:**
```thagore
i = i + 1
```

### 3. No `+=` or `-=` operators

❌ **Wrong:**
```thagore
total += x
```

✅ **Correct:**
```thagore
total = total + x
```

### 4. Printing integers — print only accepts `str`

❌ **Wrong:**
```thagore
let n = 42
println(n)
```

✅ **Correct:**
```thagore
import std.string as string

func main() -> i32:
  let n = 42
  println(string.from_int(n))
  return 0
```

### 5. String concatenation — no `+` operator on strings

❌ **Wrong:**
```thagore
let s = "hello" + " world"
```

✅ **Correct:**
```thagore
import std.string as string

func main() -> i32:
  let s = string.concat("hello", " world")
  println(s)
  return 0
```

### 6. No array literals or fixed-size array types

❌ **Wrong:**
```thagore
let arr = [1, 2, 3]
let arr: [i32; 3] = [1, 2, 3]
```

✅ **Correct** (arrays come from runtime APIs):
```thagore
import std.io as io

func main() -> i32:
  let values = io.read_ints(3)
  return 0
```

### 7. No range loops

❌ **Wrong:**
```thagore
for i in 0..10:
  println("x")
```

✅ **Correct** (use `while` for counted loops):
```thagore
func main() -> i32:
  let i: i32 = 0
  while (i < 10):
    println("x")
    i = i + 1
  return 0
```

### 8. Features that are not implemented

The following are **not in the current compiler** and will cause errors:

| Feature | Status |
|---------|--------|
| `enum` | not implemented |
| `match` | not implemented |
| `defer` | not implemented |
| `type` alias | not implemented |
| `trait` / `impl for` | not implemented |
| closures / lambdas | not implemented |
| array literals `[1, 2, 3]` | not implemented |
| range loops `0..10` | not implemented |
| string interpolation | not implemented |
| operator overloading | not implemented |

### 9. Wrong indentation

❌ **Wrong (tabs or 4 spaces):**
```thagore
func main() -> i32:
    return 0
```

✅ **Correct (2 spaces):**
```thagore
func main() -> i32:
  return 0
```

Tabs are rejected. Odd-count spaces are rounded down (3 spaces → treated as 2).

## Debugging Strategies

### 1. Use print debugging

Insert `println()` calls to trace execution:

```thagore
import std.string as string

func compute(n: i32) -> i32:
  println(string.concat("input: ", string.from_int(n)))
  let result = n * 2
  println(string.concat("result: ", string.from_int(result)))
  return result
```

### 2. Use `--emit-llvm` to inspect IR

```bash
thagc build program.tg --emit-llvm
```

Produces a `.ll` file with the generated LLVM IR.

### 3. Use `thagc check`

Typecheck without linking:

```bash
thagc check program.tg
```

### 4. Simplify to isolate the issue

Strip the program down to the smallest form that reproduces the error. Add back pieces one at a time.
