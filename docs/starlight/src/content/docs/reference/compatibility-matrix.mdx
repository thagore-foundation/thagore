# Compatibility Matrix

## Platform Support

| Platform | Architecture | Status |
|----------|-------------|--------|
| Windows | x86-64 | ✅ Supported |
| Linux | x86-64 | ✅ Supported |
| Linux | ARM64 (AArch64) | ✅ Supported |
| macOS | ARM64 (Apple Silicon) | ✅ Supported |
| macOS | x86-64 | ⚠️ Untested |

## Language Feature Status

### Core Features (Implemented)

| Feature | Status |
|---------|--------|
| `func` declarations | ✅ Implemented |
| `let` variables | ✅ Implemented |
| `if`/`else` | ✅ Implemented |
| `while` loops | ✅ Implemented |
| `for item in array` | ✅ Implemented |
| `break` / `continue` | ✅ Implemented |
| `struct` definitions | ✅ Implemented |
| `impl` blocks + methods | ✅ Implemented |
| `extern func` (C FFI) | ✅ Implemented |
| `import` module system | ✅ Implemented |
| `const` declarations | ✅ Implemented |
| `pub` keyword | ✅ Parsed (no visibility effect yet) |
| Generic functions | ✅ Implemented (`Ordered`, `Eq`, `Numeric` constraints) |
| `intent` blocks | ✅ Parsed and lowered |
| `flow` blocks | ✅ Parsed and lowered |
| String builtins (`print`, `println`, etc.) | ✅ Implemented |
| Comments (`#`) | ✅ Implemented |

### Not Implemented

| Feature | Status |
|---------|--------|
| `enum` | not implemented |
| `match` | not implemented |
| `trait` / `impl for` | not implemented |
| `type` alias | not implemented |
| `defer` | not implemented |
| `unsafe` blocks | not implemented |
| `comptime` | not implemented |
| closures / lambdas | not implemented |
| range loops (`0..10`) | not implemented |
| array literals (`[1, 2, 3]`) | not implemented |
| array indexing (`arr[i]`) | not implemented |
| fixed-size array types (`[T; N]`) | not implemented |
| string interpolation | not implemented |
| operator overloading | not implemented |
| `loop` keyword | not implemented |
| `?` result operator | not implemented |
| generic structs (end-to-end) | not implemented |

<Aside type="note" title="Feature Status Legend">
- ✅ **Implemented** — fully working in the current compiler
- ⚠️ **Partial** — parsed or partially lowered, limited codegen
- **not implemented** — does not exist in the current compiler
</Aside>
