# Functions

```python title="functions.tg" mark={1,4}
func add(a: i32, b: i32) -> i32:
    return a + b

func main() -> i32:
    let v = add(10, 32)
    print(v)
    return 0
```

## Notes

1. `func main() -> i32` vẫn là entrypoint tường minh khi bạn muốn kiểm soát rõ luồng chạy.
2. Nếu source không có `main`, compiler sẽ tự sinh entrypoint `main` từ top-level script statements.

<Aside type="note" title="Generic Signatures">
Generic clause trong header có thể xuất hiện ở source (`func id[T](x: T)`), và được lowering strip/mangle theo pipeline hiện tại.
</Aside>
