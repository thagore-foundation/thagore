# Syntax Overview

Thagore uses **Python-like syntax** with indentation-based scoping. Every block is opened by a `:` and indented. Source files use the `.tg` extension.

<Aside type="tip" title="Key Syntax Rules">
- **Indentation defines blocks** — use 4 spaces (or consistent indentation)
- **No semicolons** — each statement is one line
- **Parentheses required** in `if` and `while` conditions: `if (x > 0):`
- **Comments** use `#` (line comment) or `//` (also supported)
- **File extension** is `.tg`
</Aside>

## Quick Reference

```python title="complete_example.tg"
# Import a standard library module
import fs

# Define a struct
struct Point:
    x: i32
    y: i32

# Implement methods on the struct
impl Point:
    func magnitude(self) -> i32:
        return self.x * self.x + self.y * self.y

# Define a function
func greet(name: String) -> String:
    return "Hello, " + name + "!"

# Entry point
func main() -> i32:
    let p = Point(3, 4)
    let mag = p.magnitude()
    print(mag)

    let msg = greet("Developer")
    print(msg)

    let i = 0
    while (i < 5):
        print(i)
        i = i + 1

    return 0
```

## Minimal Program

The simplest valid Thagore program:

```python title="minimal.tg"
print("Hello!")
```

Thagore supports **top-level statements** — if your source has no `func main()`, the compiler wraps top-level code in an auto-generated `main` function.

## Program with Explicit Entry Point

```python title="explicit_main.tg"
func main() -> i32:
    print("Hello from main!")
    return 0
```

<Aside type="note" title="Return Code Convention">
`func main() -> i32` is the standard entry point. Return `0` for success, non-zero for errors. This matches C/Unix conventions.
</Aside>
