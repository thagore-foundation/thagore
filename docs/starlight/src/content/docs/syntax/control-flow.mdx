# Control Flow

## if/else + while

```tg title="if-while.tg" mark={3,6}
func main() -> i32:
    let i = 0
    while (i < 5):
        if (i == 3):
            print(100)
        else:
            print(i)
        i = i + 1
    return 0
```

## loop keyword

```tg title="loop.tg"
loop:
    # explicit break/return pattern in body
    return 0
```

## for range header

```tg title="for-range.tg" ins={1}
for i in 0..10:
    print(i)
```

<Aside type="caution" title="Header Validation">
Validation sẽ reject range-loop không đúng dạng `for i in a..b:` nếu line mang hình thức range loop nhưng sai header.
</Aside>
