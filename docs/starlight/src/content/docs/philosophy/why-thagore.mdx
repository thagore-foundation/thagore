# Why Thagore

Thagore theo đuổi mô hình: **Python-like authoring experience** + **native executable output**.

## Core Problem

Nhiều team gặp khoảng cách giữa:

1. Tốc độ viết code với cú pháp dễ đọc.
2. Hiệu năng khi deploy production binary.
3. Khả năng interop với C/Python ecosystem.

Thagore giải quyết bằng pipeline compile native và runtime bridge rõ ràng.

## What Thagore Is Good At Today

1. Build native binary từ source `.tg`.
2. Self-host flow Stage1 -> Stage2 trong CI/release.
3. C FFI và Python bridge ở mức runtime function bridge.
4. Lowering features như `comptime` folding, header validation.
