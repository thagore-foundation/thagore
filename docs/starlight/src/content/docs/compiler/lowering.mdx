# Lowering Pipeline

Module chính: `src/frontend/lowering/pipeline.tg`.

## Responsibilities

1. Thu thập `comptime func`, fold `comptime(...)` và `comptime call`.
2. Rewrite một số header (`impl Trait for Type`, `pub`, `unsafe`).
3. Validate syntax contracts (`defer` scope, `match` header, range loop, `?` usage).

```tg title="src/frontend/lowering/pipeline.tg" mark={156,171,221}
func preprocess(source: String) -> String:
    let catalog = _collect_comptime_catalog(source)
    let folded = _fold_all_comptime_calls(catalog.source_wo_comptime_funcs, catalog.params_map, catalog.body_map)
```
