# Managed String Runtime

Runtime ABI (`thag_runtime.lib` / `libthag_runtime.a`) dung registry `ManagedString` voi `refCount`.

## Core APIs

1. `__thg_retain(ptr)`
2. `__thg_release(ptr)`
3. `__thg_str_free(s)` -> `__thg_release(s)`

## Contract

1. Buffer tao qua runtime managed path se duoc dang ky vao table.
2. `release` giam ref-count, free khi count ve nguong.
3. Pointer null/khong thuoc registry duoc xu ly an toan (no-op hoac free path guarded).

<Aside type="caution" title="Interop Ownership">
Khi crossing FFI boundary, can quy uoc ro ai retain/release string de tranh leak hoac use-after-free.
</Aside>
