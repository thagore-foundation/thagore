# Thagore Starlight Docs

## Run locally

```bash
cd docs/starlight
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Content layout

- `src/content/docs/syntax/*`: granular syntax pages (feature-per-file).
- `src/content/docs/compiler/*`: compiler internals.
- `src/content/docs/stdlib/*`: standard library references.
- `src/content/docs/integration/*`: ecosystem integration playbooks.
