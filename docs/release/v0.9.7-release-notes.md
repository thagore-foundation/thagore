# Thagore v0.9.7 (Trusting-Trust Bootstrap)

Release date: 2026-04-24

## Highlights

- **Full Trusting-Trust bootstrap proof — Linux x64 + Windows x64.**
  Every push runs `bootstrap-trusting-trust.yml`, which builds
  `stage1 → stage2 → stage3` from `compiler.tg` and verifies three
  independent gates:
  - (A) behavioural equivalence — `stage2` and `stage3` produce
    identical output on a 109-row fixture corpus (`analyze`,
    `build`, `run`).
  - (B) byte-identical artifacts — `SHA256(stage2) == SHA256(stage3)`
    after format-aware normalization (`tooling/ci/pe_normalize.py`).
  - (C) same-machine determinism — rebuilding the chain a second
    time produces the same normalized hash.
  Plus an aggregator job comparing two independent Linux ephemeral
  runners (item 6 — cross-machine determinism).
- **Format-aware binary normalizer.** `tooling/ci/pe_normalize.py`
  dispatches by magic bytes:
  - PE: zeroes COFF `TimeDateStamp`, Optional `CheckSum`, and
    Debug/Export/Resource directory timestamps.
  - ELF: zeroes `.comment`, `.note.gnu.build-id`, `.note.GNU-stack`
    section contents while preserving section headers, so binaries
    stay loadable.
  - Mach-O: zeroes `LC_UUID` payload, `LC_BUILD_VERSION` minos+sdk,
    and legacy `LC_VERSION_MIN_*` version+sdk (used by the deferred
    macOS lane).
- **Cross-machine codegen determinism via CC pin.** The Linux CI
  steps now export `CC=$LLVM_SYS_140_PREFIX/bin/clang` so the C
  compiler is byte-identical on every ephemeral runner. System
  `gcc` patch-level drift was producing 80 B size deltas in
  unrelated functions when the optimizer hit a heuristic threshold;
  pinning to LLVM 14's clang eliminates that.
- **Group-2 selfhost memory optimizations.** The `desugar.slice`,
  `lexer.scan_*`, and `c_emit.extract_*` paths now use `string.substr`
  fast paths backed by the `thag_rt_substr` runtime symbol. Peak RSS
  during the stage proof stays well under the v0.9.6 baseline cap
  (≤ 768 MB Windows, ≤ 512 MB Linux).
- **Wide stage proof corpus.** `bootstrap/selfhost/corpus/stage-proof-fixtures.txt`
  carries 109 rows (103 `analyze`, 3 `build`, 3 `run`) covering
  every `bootstrap/selfhost/frontend/*.tg` and the entire
  `bootstrap/selfhost/corpus/fixtures/**` tree.

## macOS — deferred to a follow-up release

The macOS lane infrastructure is fully implemented on
`indev-rewrite` (commits `fbd0dca1`, `308cfb15`, `2ea88e9c`) — install
script, Mach-O normalizer, `macos-13` matrix entry, and a
`codesign --remove-signature` hook in the proof script — but never
dequeued during the release CI run because GHA macOS slots were
unavailable. macOS source builds from the existing toolchain still
work; only the bootstrap reproducibility guarantee is missing.
The macOS lane will go green automatically the next time CI gets a
slot, and the gate definition in `docs/plan/bootstrap-v0.9.7.md` is
ready to widen back to all three platforms when that happens.
