# Thagore v2.3.0 (HM Inference + Generics Baseline)

Release date: 2026-03-06

## Highlights

- Added HM unification engine in HIR typechecking:
  - `compiler/include/thagc/hir/typecheck.hpp`
  - `compiler/src/middleend/hir_typecheck.cpp`
- Added type-level expression APIs:
  - `infer_expression_ty(...)`
  - `check_expression_ty(...)`
- Integrated tree-type checks in frontend `TypeChecker` for:
  - `let x: Option<T>/Result<T,E> = expr`
  - `return expr` against declared `Option<T>/Result<T,E>` return type
- Added dedicated v2.3 gate suites:
  - `tests/inference/test_hm_inference.py`
  - `tests/generics/test_monomorphized_generics.py`
  - `tests/parity/test_v23_hm_generics_pipeline.py`
