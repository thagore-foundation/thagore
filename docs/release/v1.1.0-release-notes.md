# Thagore v1.1.0 (Structured Concurrency GA)

Release date: 2026-03-01

## Highlights

### Runtime Concurrency

- Added task-tree tracing hooks:
  - `thag_task_trace_set_enabled`
  - `thag_task_trace_enabled`
  - `thag_task_trace_set_hook`
  - `thag_task_scope_dump_tree`
- Deadlock diagnostics now print scope id + task tree snapshot for faster triage.
- Tuned deadlock detection to avoid false positives in long-running scope churn workloads.

### Concurrency Quality Gates

- Added long-running soak lane:
  - `tests/soak/test_concurrency_long_running.py`
- Added P0/P1 bug gate registry:
  - `contracts/concurrency/p0_p1_registry.json`
- Added extra native regression coverage for nursery lifetime semantics and false-deadlock guardrails.

### Language (`flow`) MVP

- Parser and AST support for:
  - `flow`
  - `step`
  - `undo`
  - `retry`
  - `timeout`
  - `idempotent`
  - `irreversible`
- Compile-time validation for flow semantics:
  - retry requires idempotent
  - step cannot be both undo + irreversible
  - side-effect step requires undo or irreversible

## Gate Result

- v1.1 gate passed:
  - no open P0/P1 concurrency bugs in registry
  - long-running soak stable (`3600.931s`, OK)
  - runtime and flow integration suites passing
