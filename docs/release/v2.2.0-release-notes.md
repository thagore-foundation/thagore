# Thagore v2.2.0 (HIR + Bidirectional Type Checking)

Release date: 2026-03-06

## Highlights

- Added typed HIR expression model:
  - `compiler/include/thagc/hir/expr.hpp`
  - `compiler/include/thagc/hir/typecheck.hpp`
- Added shared type representation layer:
  - `compiler/include/thagc/ty/ty.hpp`
- Implemented HIR lowering + inference/check pass:
  - `compiler/src/middleend/hir_typecheck.cpp`
- Integrated HIR bidirectional checks into `TypeChecker` for:
  - `let x: T = e` annotation validation
  - `return e` validation against declared function return type
- Kept compatibility fallback to existing expression-type pipeline to avoid behavioral regressions while v2.2 lands.

## Changelog

- typed HIR, bidirectional type checker, type-mismatch errors with source underlines.
