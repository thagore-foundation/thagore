# Thagore v1.9.0 (Span System + Token Pipeline)

Release date: 2026-03-05

## Highlights

- Frontend now has first-class byte-offset spans:
  - added `Span` in `compiler/include/thagc/frontend/span.hpp`
  - `Token` now carries `span`
  - lexer populates spans for all emitted tokens
- Added source map infrastructure:
  - `compiler/include/thagc/frontend/source_map.hpp`
  - `compiler/src/frontend/source_map.cpp`
- Parser now keeps real token stream context (`std::span<const Token>`) instead of discarding tokens.
- Span propagation wired into AST/core pipeline (`AstFunction`, `AstImport`, `AstFlowStep`, `AstStatement`, `CoreStmt`).
- Diagnostic rendering now supports caret ranges in `thagc check`.

## Changelog

- Added span-aware diagnostics for parse errors, including source underlines (`^^^`) in `thagc check`.

## Gate Result

- `cmake --build build` passes.
- `thagc check` on an invalid file prints caret diagnostics with line/column ranges.
- Existing valid examples still pass `thagc check`.
