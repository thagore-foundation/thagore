# Thagore v0.6.0 (Concurrency Primitives Alpha)

Release date: 2026-02-27

## Why This Release

`v0.6.0` ships one roadmap milestone completely instead of waterfalling across multiple versions.
Primary goal: production-capable concurrency primitives alpha with deterministic behavior gates.

## Highlights

### Runtime

- Task-scope scheduler upgraded from thread-per-task pattern to queued worker model.
- Nursery API available (`thag_nursery_create`) on the same scope runtime model.
- Cancel + timeout propagation behavior hardened.
- Async event-loop runtime API added:
  - `thag_async_runtime_create/destroy`
  - `thag_async_spawn`
  - `thag_async_sleep`
  - `thag_async_wait_idle`

### Compiler Safety

- `Rc`/`Arc` checks kept strict at Send/Sync boundaries.
- `E_SEND_SYNC_004` includes actionable migration hint (`use Arc`).
- Typestate guards for resource state misuse (`open/read/write/close`) remain enforced.

### IO/Platform Support Relevant to Concurrency Lanes

- WebSocket path upgraded with HTTP upgrade handshake + framed text send (POSIX path).
- DB path supports SQLite when available, deterministic fallback otherwise.
- HTTP runtime keeps curl path when available.

### Test and Gate Additions

- Native concurrency regression suite added:
  - race-stress task spawning
  - timeout/cancel determinism
  - async event-loop timer behavior
- Full repository tests pass on this release cut.

## Notes

- This is an Alpha milestone (`v0.6`) and intentionally stops at the concurrency primitives scope.
- Features from later milestones are not used to redefine this release scope.
