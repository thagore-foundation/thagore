# Thagore v2.0.0 (Real Recursive-Descent Parser)

Release date: 2026-03-06

## Highlights

- Replaced line-by-line parser with recursive-descent token-stream parser in frontend.
- Removed third-pass backend re-parse dependency by evaluating `AstExpr` first with safe fallback to legacy expression lowering.
- Kept language compatibility across existing features (imports, tuples/arrays, try-operator, struct methods, typestate, stdlib IO).
- Hardened backend pointer coercion for LLVM typed-pointer compatibility in extern/runtime and struct/method lowering paths.
