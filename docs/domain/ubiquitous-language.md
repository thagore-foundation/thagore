# Ubiquitous Language

## Core Terms

- Source Unit: one `.tg` compilation input.
- Token Stream: lexical output consumed by parser.
- AST Program: parsed syntax tree root representation.
- Typed Program: semantically validated program.
- Core Program: lowered IR prior to LLVM emission.
- Emit Contract: rule that emitted artifacts match source semantics.
- Parity Snapshot: frozen behavior contract from baseline branch.
- Target Pack: bundled LLVM lane and target metadata.

## Team Rule
These terms must be used consistently in code, PRs, ADRs, and issues.
