# v1.4 Migration and Rollback Playbook

This runbook standardizes migration from v1.3 to v1.4 and safe rollback when a release must be reverted.

## Scope

- Compiler binary: `thagc`
- Package manager and project workflow: `drago`
- Language changes in v1.4:
  - `state <Set>: <Variant> | ...` parser/typechecker support
  - diagnostics with fix suggestions
  - `thagc fix`, `thagc repl`, `thagc lsp --stdio`

## Pre-migration checklist

1. Ensure CI on current branch is green on Linux/macOS/Windows.
2. Freeze release inputs:
   - `ROADMAP.md`
   - `contracts/manifest.json`
   - release workflows under `.github/workflows/`.
3. Record baseline:
   - `thagc --version`
   - latest release tag and checksums
   - current installer scripts (`thagup*.sh`, `thagup.ps1`).

## Migration procedure

1. Build and test locally:
   - `cmake -S . -B build-llvm21 -G Ninja -DLLVM_DIR=/usr/lib/llvm-21/lib/cmake/llvm`
   - `cmake --build build-llvm21 -j$(nproc)`
   - `THAGC_BIN=build-llvm21/compiler/thagc python3 -m unittest discover -s tests -p "test_*.py"`
2. Validate cross-platform smoke workflow:
   - Trigger `.github/workflows/cross-platform-smoke.yml`
   - Require all matrix jobs pass.
3. Validate release workflow artifact integrity:
   - Trigger `.github/workflows/release.yml` in a dry run tag.
   - Verify generated archive checksums and installer scripts.
4. Publish release tag and artifacts.
5. Sync landing/install scripts after release publish.

## Rollback triggers

Rollback is required when one of the following appears after release:

- deterministic CI regression on any supported OS,
- broken install/update path,
- runtime crash on basic compile-run flow,
- major diagnostic regression (missing file/line/column output).

## Rollback procedure

1. Identify last known-good tag (LKG).
2. Re-publish installer pointers to LKG assets:
   - release channel metadata
   - `thagup` script endpoints
3. Re-run smoke checks against LKG artifacts.
4. Announce rollback scope and impacted versions.
5. Open follow-up fix issue and prepare patch release.

## Post-rollback verification

1. Fresh machine install succeeds with LKG installer.
2. `thagc --version` matches LKG.
3. `drago run` works on a fresh sample project.
4. Cross-platform smoke workflow green on rollback commit.
