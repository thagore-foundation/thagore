# External Contributor PR Log

This ledger tracks merged pull requests from contributors outside the core maintainer account.

## Criteria

- Pull request merged to `main`.
- Author is not listed as core maintainer in `CODEOWNERS`.
- Change includes test coverage or contract/documentation updates.

## First external contributor PR milestone

- Status: completed
- Recorded contributor: `thagore-community`
- Pull request reference: `thagore-foundation/thagore#1`
- Merge scope: community launch docs + workflow hardening

## Ongoing tracking format

- `date`
- `contributor`
- `pull request`
- `scope`
