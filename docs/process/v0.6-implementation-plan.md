# v0.6 Implementation Plan (Single-Milestone Mode)

This plan executes one roadmap milestone only: `v0.6`.
No waterfall into `v0.7+` scope during this cycle.

## Phase 1: Runtime Core

- Replace thread-per-task behavior with queue + worker scheduler.
- Keep scope/nursery API behavior deterministic.
- Ensure parent-child cancellation propagation and timeout behavior.

Exit criteria:
- Scope lifecycle tests and timeout/cancel tests pass repeatedly.

## Phase 2: Compiler Safety

- Enforce `Send/Sync` checks at thread-boundary usage sites.
- Keep `Rc`/`Arc` distinction explicit and actionable.
- Emit `E_SEND_SYNC_004` with fix hint (`use Arc`).

Exit criteria:
- Memory-model integration tests pass, including negative diagnostics.

## Phase 3: Determinism and Stress Gates

- Add native regression lanes for race/deadlock-like patterns.
- Add deterministic cancel/timeout stress runs.
- Validate async runtime idle/wakeup behavior under timers.

Exit criteria:
- Concurrency regression suite passes consistently in CI lanes.

## Phase 4: Release

- Freeze scope to v0.6 checklist only.
- Bump version to `0.6.0`.
- Publish release notes and release checklist.

Exit criteria:
- `VERSION=0.6.0`
- Full test suite passes
- v0.6 checklist complete
