# Tài liệu tiếng Việt v1.5

## Mục tiêu

Thagore v1.5 hướng tới:

- hiệu năng native,
- an toàn concurrency,
- trải nghiệm học tập dễ tiếp cận cho người mới.

## Luồng học đề xuất

1. Bắt đầu với `docs/tutorials/beginner.md`.
2. Chuyển sang `docs/tutorials/intermediate.md`.
3. Hoàn thiện với `docs/tutorials/advanced.md`.
4. Làm project thực hành theo `docs/tutorials/build-a-bot.md`.

## Luồng phát triển tiêu chuẩn

- Tạo project: `drago new app`
- Chạy: `drago run`
- Kiểm tra compiler: `thagc check src/main.tg`
- Sửa lỗi phổ biến: `thagc fix src/main.tg`
- Kiểm tra typestate: `thagc state explain src/main.tg`
