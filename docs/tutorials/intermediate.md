# Intermediate Tutorial (v1.5)

## Goal

Build a multi-file CLI with imports, structs, enums, and Result/Option handling.

## Steps

1. Split code into modules.
2. Use `import` and `from ... import ...`.
3. Add `struct` with methods and `enum` for domain states.
4. Use `Result`/`Option` and `match`.
5. Run checks:
   - `thagc check src/main.tg`
6. Build and run:
   - `drago build`
   - `drago run`

## Outcome

You can deliver a maintainable CLI project with typed module boundaries.
