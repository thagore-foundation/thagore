# Beginner Tutorial (v1.5)

## Goal

Build and run your first Thagore program in minutes.

## Steps

1. Install toolchain (`thagc` + `drago`).
2. Create project:
   - `drago new hello`
3. Run:
   - `drago run`
4. Edit `src/main.tg`:
   - use `let`, `if`, loops, and `print`.
5. Validate:
   - `thagc check src/main.tg`

## Outcome

You can compile and run a native Thagore binary locally.
